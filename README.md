# Home Decor & Construction Planning Studio

## Install and run (Windows)
1. Install Python 3.10 or newer from python.org (tick "Add Python to PATH").
2. Unzip this folder.
3. Double-click run.bat. First run installs packages (internet needed once).
4. Browser opens at http://127.0.0.1:8000

Mac/Linux: ./run.sh

## Notes
- 3D view loads Three.js from the internet (jsdelivr). Needs internet while using the 3D tab.
- AI images: put OPENAI_API_KEY in .env (optional). Without it the app shows a "not configured" message.
- Data is stored in backend/studio.db.
- Costs are estimates with editable SAMPLE rates. Supplier data is sample data. Not a structural design.
